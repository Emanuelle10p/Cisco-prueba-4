Uso de Inteligencia Artificial en MiniAcad

En esta página se documentan los prompts e interacciones con herramientas de IA utilizadas para apoyar la planificación y el desarrollo del proyecto.

Prompts utilizados

  1. Prompt 1 (Estructura semántica): "Genera un esquema HTML5 con elementos semánticos (header, nav, main, article, section, footer) accesible según normas WCAG AA para una academia infantil."

    Aporte: Ayudó a definir una estructura limpia y optimizada para lectores de pantalla.

  2. Prompt 2 (CSS Layout): "Crea reglas de CSS Grid para organizar tarjetas de cursos y Flexbox para la barra de navegación responsiva."

    Aporte: Proveyó las bases para el diseño adaptativo en el archivo `estilos.css`.

  3. Prompt 3 (Accesibilidad JS): "Escribe una función simple en JavaScript para desplegar acordeones usando atributos aria-expanded y aria-controls."

    Aporte: Permitió implementar el componente FAQ interactivo de forma completamente accesible por teclado.

  4. Prompt 4 (Verificación de Contraste): "Evalúa la paleta de colores azul #0056b3 y texto blanco #ffffff frente al estándar de contraste WCAG AA."

    Aporte: Garantizó una relación de contraste superior a 4.5:1 para legibilidad de usuarios con visión reducida.

  5. Prompt 5 (Contenido Pedagógico): "Genera una explicación accesible de menos de 100 palabras con oraciones cortas sobre cómo sumar dirigida a niños de 7 años."

    Aporte: Proporcionó el texto adaptado para la lectura de la primera lección.
